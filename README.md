# Weather Website

## Overview

This weather website provides detailed weather information for any city you search. It displays current temperature, a 24-hour forecast, and other key metrics like wind speed, precipitation percentage, UV index, and "feels like" temperature.

## Features

- **City Search:** Easily search for weather data for any city worldwide.
- **Real-time Temperature:** Get the current temperature in your desired units (Celsius or Fahrenheit).
- **24-Hour Forecast:** View hourly temperature predictions for the next 24 hours.
- **Additional Metrics:** Access wind speed, precipitation percentage, UV index, and "feels like" temperature for a comprehensive understanding of weather conditions.

## Technologies Used

- **Visual Crossing API:** Fetches weather data from the Visual Crossing API.
- **Tailwind CSS:** Provides a utility-first CSS framework for efficient styling.
- **Webpack:** Bundles JavaScript modules and assets for efficient delivery.

## Getting Started

1. **Clone the Repository:**

   ```bash
   git clone https://github.com/your-username/weather-website.git
   ```

2. **Install Dependencies:**

   ```bash
   cd weather-website
   npm install
   ```

3. **Start the Development Server:**

   ```bash
   npm start
   ```

   The website will be accessible at `http://localhost:3000`.

## Usage

1. **Search for a City:** Enter the city name in the search bar and click the "Search" button.
2. **View Weather Details:** The website will display the current temperature, 24-hour forecast, and other relevant metrics.
